7. **Commit + push** — `git add . && git commit -m "[v3.0][agent-id] P1-C03: description" && git push origin dev`
8. **Mark it DONE** — update V3_BOARD.md + roll call below
9. **Write to `AGENT_LOG.md`** — leave a message for the next cat
10. **Pick next task** or unblock another agent

## 🗨️ Agent Communication Protocol

Cats need to talk. Here's how Miau agents communicate with each other.

### The Agent Log (`AGENT_LOG.md`)

**`AGENT_LOG.md`** is the shared message board for ALL agents. It sits at the repo root and contains:
- Status updates from every agent after each session
- Blockers and requests for help (@tag other agents)
- Dependencies and handoff notes
- Session summaries so the next agent knows what happened

**When you start a session:**
1. Read `AGENT_LOG.md` from the bottom — see what other agents have been doing
2. Check the Roll Call above for who's active and who's blocked
3. If someone left a message with your @tag, respond to it

**When you finish a task:**
1. Update the Roll Call section above
2. Add an entry to `AGENT_LOG.md` with your status, what you completed, and what's next
3. @-tag any other agents who need to know about your work

### Inter-Agent Message Format

```
### YYYY-MM-DD — AgentName — Status: 🟢 Active / 🟡 Blocked / ✅ Done

**Completed:** task1, task2
**Working on:** task3
**Blocked:** reason (if any)
**Next:** what I'll do next session
**Dependencies:** @agent — I need X from you before I can continue
**Message:** @agent — specific note for another cat
```

### Communication Rules

| Rule | Why |
|------|-----|
| **1. Always read `AGENT_LOG.md` first** | Don't duplicate work or break dependencies |
| **2. Always write to `AGENT_LOG.md` when done** | The next agent needs to know what happened |
| **3. @-tag other agents for blockers** | Don't sit on a blocked task — ask for help |
| **4. Use @all for urgent messages** | When you need immediate attention |
| **5. Commit `AGENT_LOG.md` with every push** | The log travels with the code |
| **6. One agent per file (no overlapping edits)** | Avoid merge conflicts and stepping on each other |

### Urgent Messages

For urgent inter-agent communication:
- **@all** — tag everyone in `AGENT_LOG.md`
- **Commit with `[URGENT]` prefix** — catches attention in commit log
- **Update the Roll Call** — set your status to 🟡 Blocked and explain why

### Session Handoff

When handing off work to another agent:

```
1. Update AGENT_LOG.md with your progress
2. Update Roll Call (set Status, update Working On)
3. Update V3_BOARD.md (mark tasks as DONE or IN PROGRESS)
4. Push all changes
5. Leave a clear message in AGENT_LOG.md about what's next
```

The next agent reads `AGENT_LOG.md`, sees your message, and picks up where you left off.
