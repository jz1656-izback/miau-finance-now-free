# CatMiau Page Format Specification

A `.miau` file is a structured page specification with exactly 7 lines:

```
Page: <Name>
Cat: <emoji>
Function: <one line>
Description: <paragraph explaining what it does>
API: <endpoint or "—">
Output: <what it shows>
Tuna: <number>
```

Each page represents a component, service, or app in the Miau Finance ecosystem. Pages are 5-8 lines of description. The Tuna value determines the page's economic weight in the tuna economy — every page pays the cat in tuna tokens. Higher tuna values indicate higher complexity and revenue generation. The Cat emoji identifies the feline guardian of that page.
