# 🚀 Miau Finance — Cat Rocket Landing Page

A retro terminal-themed landing page for the Miau Finance ecosystem.
Features a cat riding a rocket with animated flames, CRT scanlines,
and links to all Miau products.

## Quick Start

```bash
python3 -m http.server 8080 --directory apps/landing-page/
# Open: http://localhost:8080
```

## Links

All product cards link to their respective apps via localhost ports.
When deployed to Hetzner, swap `localhost:PORT` for real subdomains.

## Design

- Green-on-black CRT terminal aesthetic
- Scanline overlay + screen vignette
- Animated rocket flames with flicker effect
- Floating cat on rocket with vertical bob animation
- Glitch text effect on title
- Typewriter tagline animation
- Starfield particle background
- Command-line style prompt with cycling fake commands
