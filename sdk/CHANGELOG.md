# SDK Changelog

## v1.1.0 (2026-05-19)
- JavaScript SDK: added market.js, portfolio.js, trading.js standalone modules with full API coverage
- DeFi SDK: wallet connect, protocol data (Uniswap, Aave, Curve, Lido, Yearn, Maker), Solana DeFi, yield aggregator, cross-chain bridges
- NFT SDK: portfolio tracking, floor price monitoring, rarity scoring, trait-based valuation, marketplace listings
- Endpoint coverage expanded from 107 → 149 DeFi+NFT endpoints

## v1.0.0 (2026-05-19)
- Initial Python SDK: core client, market, portfolio, trading, AI, social modules
- Initial JavaScript SDK: MiauClient with convenience methods
- Initial curl SDK: 12 endpoint groups (market, portfolio, trading, AI, analytics, etc.)
- SDK auto-generation script from OpenAPI spec
