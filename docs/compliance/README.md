## Disclaimer

These documents are templates for the Miau Finance platform. The following placeholders must be filled in before use:

- `[Vorname Nachname / Company Name]` — your legal entity name
- `[Straße Hausnummer]`, `[PLZ Ort]` — physical address
- `[Telefonnummer]` — contact phone
- `[USt-IdNr.]` — VAT ID (if applicable)
- `[Name]` — responsible persons (ISB, DPO, Compliance)
- `[Hosting-Provider]` — your hosting provider
- `[Anzahl]` — approximate user count

This documentation is provided for informational purposes and does not constitute legal advice. Consult a qualified attorney (Fachanwalt für IT-Recht) before publication.
