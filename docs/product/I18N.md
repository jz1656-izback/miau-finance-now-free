# Internationalization (i18n)

Miau Finance supports 9 languages across the terminal UI, number/currency formatting, and date display.

## Supported Locales

| Locale | Language | Native Name | File |
|--------|----------|-------------|------|
| `en` | English | English | Default (built-in) |
| `de` | German | Deutsch | `frontend/src/locales/de.ts` |
| `fr` | French | Français | `frontend/src/locales/fr.ts` |
| `es` | Spanish | Español | `frontend/src/locales/es.ts` |
| `ja` | Japanese | 日本語 | `frontend/src/locales/ja.ts` |
| `zh` | Chinese | 中文 | `frontend/src/locales/zh.ts` |
| `ko` | Korean | 한국어 | `frontend/src/locales/ko.ts` |
| `pt` | Portuguese | Português | `frontend/src/locales/pt.ts` |
| `ru` | Russian | Русский | `frontend/src/locales/ru.ts` |

## System Architecture

```
frontend/src/lib/i18n.ts          ← Registry: getCurrentLocale, setLocale, t()
frontend/src/locales/*.ts         ← Translation files (one per locale)
Terminal.tsx                       ← Language selector in status bar
```

Each locale file exports a flat key-value map:

```ts
// frontend/src/locales/de.ts
export default {
  'market.live': 'Live-Kurse',
  'portfolio.value': 'Portfoliowert',
  'command.not_found': 'Befehl nicht gefunden',
  'common.loading': 'Laden...',
  'common.error': 'Fehler',
  'common.success': 'Erfolgreich',
  'time.just_now': 'gerade eben',
  'time.minutes_ago': 'vor {n} Minuten',
  'time.hours_ago': 'vor {n} Stunden',
}
```

## Usage

### Terminal Commands

```bash
miau@finance:~$ theme de          # Switch to German locale
miau@finance:~$ theme list         # List available locales
miau@finance:~$ theme en           # Switch back to English
```

The `theme` command toggles between locale themes. Language is saved to `localStorage` and persists across sessions.

### Auto-Detection

On first visit, Miau Finance detects the browser language via `navigator.language`:

| Browser Language | Selected Locale |
|-----------------|----------------|
| `de-DE`, `de-AT`, `de-CH` | `de` |
| `fr-FR`, `fr-CA`, `fr-BE` | `fr` |
| `ja-JP` | `ja` |
| `zh-CN`, `zh-TW` | `zh` |
| Any other | `en` (fallback) |

### Number & Currency Formatting

Locales affect how numbers, currencies, and dates are displayed via `Intl` APIs:

```ts
// 1234567.89 → en: "1,234,567.89"  de: "1.234.567,89"
Intl.NumberFormat(locale).format(amount)

// Date formatting
Intl.DateTimeFormat(locale, { dateStyle: 'medium' }).format(date)

// Currency
Intl.NumberFormat(locale, { style: 'currency', currency: 'USD' }).format(price)
```

### Programmatic Access

```ts
import { getCurrentLocale, setLocale, t } from '../lib/i18n'

const locale = getCurrentLocale()      // 'en' | 'de' | 'fr' | ...
setLocale('de')                         // Switch to German
const label = t('market.live')          // Translated string
```

## Translation Keys

| Key | Purpose | Example (en) | Example (de) |
|-----|---------|--------------|--------------|
| `market.live` | Live price header | "Live Prices" | "Live-Kurse" |
| `portfolio.value` | Portfolio value | "Portfolio Value" | "Portfoliowert" |
| `command.not_found` | Unknown command | "Command not found" | "Befehl nicht gefunden" |
| `common.loading` | Loading state | "Loading..." | "Laden..." |
| `common.error` | Error state | "Error" | "Fehler" |
| `common.success` | Success state | "Success" | "Erfolgreich" |
| `time.just_now` | Recent time | "just now" | "gerade eben" |
| `time.minutes_ago` | Relative time | "{n} minutes ago" | "vor {n} Minuten" |

## Adding a New Locale

1. **Create the translation file:** `frontend/src/locales/xx.ts` (replace `xx` with your ISO 639-1 code)
2. **Register the locale:** Add to `SUPPORTED_LOCALES` in `frontend/src/lib/i18n.ts`
3. **Add native name:** Insert into the locale map with the language's own name
4. **Test:** Type `theme xx` in the terminal to verify

```ts
// Example: frontend/src/locales/it.ts
export default {
  'market.live': 'Prezzi in tempo reale',
  'portfolio.value': "Valore del portafoglio",
  'command.not_found': 'Comando non trovato',
  'common.loading': 'Caricamento...',
  'common.error': 'Errore',
  'common.success': 'Successo',
  'time.just_now': 'proprio ora',
  'time.minutes_ago': '{n} minuti fa',
}
```

## Locale-Aware Features

- **Number formatting:** Thousands separators, decimal points per locale
- **Currency display:** Symbol position (€10 vs 10€), decimal precision
- **Date formatting:** `dd/mm/yyyy` (EU) vs `mm/dd/yyyy` (US) vs `yyyy-mm-dd` (ISO)
- **Week start:** Monday vs Sunday depending on locale
- **Time format:** 24h (EU) vs 12h (US) depending on `Intl.DateTimeFormat`
