# 🐱 MIAU FINANCE — FAQ

### What is Miau Finance?
A cat-themed Bloomberg Terminal competitor. 515+ APIs, 160+ commands, AI advisor, 3D globe, quant engine — all in your terminal.

### Is it free?
Yes. Free tier includes market data and portfolio tracking. Pro (€99/mo) unlocks AI advisor and paper trading. Enterprise (€396/mo) adds custom deployment and SLA.

### Is it open source?
No. Proprietary (All Rights Reserved) since v2.1.0. Source visible on GitHub but not licensed for commercial use.

### Do I need coding experience?
No. All commands are intuitive: `price AAPL`, `ta AAPL`, `signal AAPL`.

### What brokers are supported?
Alpaca, Interactive Brokers, DEGIRO, Saxo, Rakuten, Zerodha.
