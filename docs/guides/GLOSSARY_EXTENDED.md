# 🐱 MIAU FINANCE — Glossary

## Financial Terms

| Term | Definition |
|------|------------|
| **Alpha** | Excess return of an investment relative to its benchmark. Cat alpha = 100% (🐱). |
| **Beta** | Measure of volatility relative to the market. Cat beta = sleeping all day (0.0). |
| **CAPM** | Capital Asset Pricing Model. Calculates expected return based on risk. The cat uses CAPM then ignores it. |
| **VaR** | Value at Risk. Maximum expected loss over a period. The cat calculates it then buys tuna anyway. |
| **CVaR** | Conditional VaR. Average loss beyond VaR. Also known as "how much is the cat willing to lose for tuna." |
| **Sharpe Ratio** | Risk-adjusted return. >1 is good. The cat's Sharpe ratio is ∞ because cats take no risk. |
| **Granger Causality** | Statistical test: does X predict Y? The cat Granger-causes everything. |
| **Cointegration** | Two assets that move together long-term. Like cat and nap. |
| **OLS** | Ordinary Least Squares. Line of best fit. The cat fits on any surface. |
| **MACD** | Moving Average Convergence Divergence. Momentum indicator. The cat diverges when it sees tuna. |
| **RSI** | Relative Strength Index. Oversold <30, overbought >70. The cat is always neutral (50). |
| **Bollinger Bands** | Volatility bands around moving average. The cat expands its bands when threatened. |
