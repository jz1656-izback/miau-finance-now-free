# 🦄 ProductHunt Launch

## Tagline
🐱 Miau Finance — Proprietary, terminal-based autonomous finance platform. Stocks, crypto, DeFi, NFT, ESG. All from your keyboard.

## Description

**Miau Finance** is a cat-themed, terminal-based financial analytics platform that brings institutional-grade tools to your keyboard — free, proprietary commercial, and hosted.

Think Bloomberg Terminal, but:
- ✅ Open source commercial
- ✅ Self-hosted (your data, your infrastructure)
- ✅ Terminal-native (split panes, 5 themes, autocomplete, cat companion)
- ✅ Brokers: Alpaca, IBKR, Saxo, DEGIRO, Rakuten, Zerodha
- ✅ DeFi: WalletConnect, Uniswap, Aave, Curve, Lido, Maker, Yearn
- ✅ Analytics: DCF, WACC, LBO, Comps, Monte Carlo, VaR, Greeks
- ✅ ESG: Environmental, Social, Governance scores + carbon tracking
- ✅ AI: Advisor, NLP, autonomous trading agents
- ✅ NFT: Portfolio tracker, floor prices, rarity scoring
- ✅ SDK: Python + JavaScript + curl
- ✅ 120+ API endpoints
- ✅ Error messages with cat jokes

**The stack:**
Python/FastAPI · React/TypeScript · Rust PyO3 · PostgreSQL · Redis · Docker · K8s

**Sheetz miau:**
```
sheetz miau -dcf AAPL   # DCF valuation
sheetz miau -wacc MSFT  # WACC calculation
sheetz miau -comps GOOGL # Comps analysis
sheetz miau -lbo AAPL   # LBO model
```
